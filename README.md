# Auth & Onboarding UI (Flutter)

A real-world Flutter implementation of authentication and onboarding flows. This project demonstrates how to build clean, responsive UI screens for login, sign up, and user onboarding.

## Features

- Clean and modern UI design
- Responsive layout that works on all screen sizes
- Smooth animations using Flutter's built-in animation widgets
- Form validation with real-time error feedback
- Password visibility toggle
- Social login buttons (Google, Apple)
- Onboarding flow with page indicators

## Technologies Used

- Flutter + Dart
- Material Design 3 Components
- Provider for state management
- Flutter Animations

## Getting Started

### Prerequisites

- Flutter SDK (3.0.0 or higher)
- Dart SDK

### Installation

1. Clone the repository
```bash
git clone https://github.com/mhmd2042/auth-onboarding-ui.git
```

2. Install dependencies
```bash
flutter pub get
```

3. Run the app
```bash
flutter run
```
